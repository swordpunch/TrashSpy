# TrashSpy

Программа для Windows: показывает удалённые файлы.

## Возможности

- **История удалений** — слежение за выбранными папками, журнал удалений в SQLite.
  Работает с момента включения слежения и только пока программа запущена.
- **Недавно удалённые** — сканирование журнала NTFS (USN), показывает удаления
  за последние дни/недели **без** предварительного слежения. Нужен запуск
  от имени администратора.
- Открытие папки удалённого файла по двойному клику.
- 5 языков интерфейса: русский, українська, English, беларуская, қазақша.

## Скачать

Готовый установник: `Setup_TrashSpy.exe` (собирается из этого кода, см. ниже).
Python на компьютере не нужен.

## Запуск из кода

```
py deleted_viewer.py
```

Только стандартная библиотека Python (tkinter входит в поставку).

## Сборка

```
py -m pip install pyinstaller pillow
py icon_make.py                        # перегенерировать иконку (необязательно)
py -m PyInstaller --onefile --windowed --name TrashSpy --icon icon.ico deleted_viewer.py
```

Установник (нужен [Inno Setup 6](https://jrsoftware.org/isinfo.php)):

```
"C:\Program Files (x86)\Inno Setup 6\ISCC.exe" setup.iss
```

## Как это работает

- Windows не хранит историю навсегда удалённых файлов, поэтому прошлое
  восстанавливается только из журнала NTFS (он циклический, обычно дни–недели).
- Удаление в Корзину — это переименование, а не удаление: такие файлы видны
  в Корзине, а не в журнале.

## Файлы

- `deleted_viewer.py` — вся программа
- `lang.py` — переводы интерфейса
- `setup.iss` — скрипт установника Inno Setup
- `icon_make.py` — генерация иконки
- `build_exe.bat` — пересборка `.exe` одной командой
